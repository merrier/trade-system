# 全 A 股日线采集与验收

入口：`npm run ingest:a-share-daily`。先按项目交易日历判断，非交易日不请求或改写数据。
北京时间 16:00 前截止到上一完整交易日；16:00 后包含当天，要求上游批量文件已经更新。
全 A 股包括沪深主板、创业板、科创板、北交所和 ST；不改变主板趋势策略与监控池范围。

准备依赖：`python3 -m pip install -r python/requirements-daily.txt`。需要 `FUYAO_API_KEY`、
`IWENCAI_API_KEY` 和现有 hithink-market-query CLI。macOS 本地运行前在 zsh 加载 `~/.zshenv`。

## 数据与失败边界

- `data/a-share/a-share-daily-unadjusted.parquet`：近 30 个完整交易日的已验收原始日线。
  OHLC 未复权，成交量单位为股，成交额为人民币元。**不能直接写入前复权、手为单位的策略缓存。**
- `coverage.json`：本轮窗口、代码表数量、完整 30 日数量、逐股逐日例外、无法解释缺口、来源及状态。
- `raw-progress.parquet`：已通过字段校验的采集进度；缺口或证据失败时保留，重跑复用。
- 代码表、问财上市日期、东方财富逐日停牌记录与 Fuyao 发行日历作为证据文件保留。
  上市前、尚未上市、全天停牌可以解释无交易记录；盘中临停不能解释缺失整根日 K。
- 数据范围已覆盖截止日时复用；正常跨日使用近 10 日 dump 重叠更新；缺口超出增量范围才下载全量。
  股票代码与交易日期为合并键。重复源记录、非交易日、无效 OHLC/量额、口径错误均拒绝。
- 无法解释的缺口使任务失败，旧的验收缓存保持不变；不补零、不前向填充，不标成零选股结果。
- 请求串行，间隔至少 2 秒；429/4001 遵守 Retry-After，至少 60/120/240 秒，最多重试 3 次。
  持续限流停止本轮；不要立即手动重跑。

缓存放在构建目录之外，避免 Vite 的 `emptyOutDir` 删除原始数据。新工作流配置为北京时间
17:30 的采集任务，仅保存数据和验收产物，不发推荐、不调用 webhook、不写主板策略缓存。
GitHub 定时任务可能延迟；工作流文件需存在默认分支，`dev` 上也需具备对应代码，才可实际启用。
专用测试分支 `codex/verify-a-share-daily` 的 push 会触发远端验证；每日定时生效仍需合入默认分支。
