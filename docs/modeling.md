# 模型训练与回测路线

本系统当前阶段以数据采集、分析和手动交易辅助为主；模型训练与回测作为后续增强层接入。

## Qlib

[Microsoft Qlib](https://github.com/microsoft/qlib) 可作为后续的训练与回测框架，用于验证每日抓取的数据是否真的有选股价值。

定位：

- 不替代问财、AKShare、Tushare 等数据源。
- 不负责实时行情抓取、涨停板接口、龙虎榜接口或自动交易。
- 作为离线研究层，负责特征工程、模型训练、回测评估和组合分析。

可使用的数据：

- `data/iwencai/main-board-YYYYMMDD.json`：主板全量行情、成交额、换手率、主力资金等。
- `data/iwencai/limit-ups-YYYYMMDD.json`：涨停原因、连板数、封单额、首封/终封时间、开板次数等。
- `data/iwencai/dragon-tiger-YYYYMMDD.json`：龙虎榜席位明细、机构/游资席位、买入额、卖出额、净买入额等。
- SQLite 表：`DailyBarRecord`、`LimitUpRecord`、`DragonTigerRecord`、`SectorRecord`、`Recommendation`。

适合验证的问题：

- 涨停原因、连板高度、封单强度是否能预测未来 1/3/5 日收益。
- 龙虎榜净买入、机构席位、知名游资席位是否能提高推荐胜率。
- 主力资金流、成交额、换手率、板块热度组合后是否能提升排序效果。
- 当前人工打分权重是否优于机器学习排序模型。

后续接入方式：

1. 将每日问财/AKShare 数据转换成 Qlib 可读取的离线数据集。
2. 生成特征：行情、资金流、涨停、龙虎榜、板块热度、风险标签。
3. 生成标签：未来 1/3/5 日收益、是否跑赢指数、最大回撤等。
4. 使用 Qlib 训练排序或回归模型。
5. 使用 Qlib 回测模型推荐结果，输出收益、回撤、换手率、胜率和风险指标。
6. 将回测稳定的模型分数接回推荐排名，作为 `modelScore` 或推荐因子之一。

第一版目标不是追求复杂模型，而是先用 Qlib 验证：当前采集的数据和人工因子是否真的能在历史回测中提供稳定增益。
